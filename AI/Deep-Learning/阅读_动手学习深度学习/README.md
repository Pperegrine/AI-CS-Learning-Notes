# Dive into Deep Learning 学习导图

本目录用于记录《动手学深度学习》（Dive into Deep Learning, D2L）的学习过程。

## 📖 内容说明

学习过程中，我会按照书籍的**章节与小节结构**进行阅读，并针对每个小节绘制对应的思维导图，对其中的重要内容进行总结和梳理。

导图主要用于整理：

- 核心概念与基本原理
- 重要公式及其含义
- 模型与算法的整体结构
- 不同知识点之间的联系
- 学习过程中容易混淆的概念
- 对章节内容的个人理解与总结

## 🎯 目的

相比单纯记录线性笔记，本目录更强调通过思维导图建立知识之间的联系，希望在学习过程中逐渐形成较为完整的深度学习知识体系。

主要目标包括：

1. **梳理知识结构**
   将书中的内容从线性章节转化为具有层次关系的知识网络。
2. **强化理解而非单纯记录**
   导图内容以理解后的总结为主，而不是直接摘录原文。
3. **方便回顾与复习**
   通过较为直观的结构快速定位某个概念以及它与其他知识点之间的关系。
4. **逐步构建深度学习知识框架**
   随着阅读进度持续补充和调整已有导图，使整个知识体系不断完善。

## 🗺️ 组织方式

内容基本按照《动手学深度学习》的原始章节顺序组织：

```
Chapter
├── Section 1
│   └── Mind Map
├── Section 2
│   └── Mind Map
├── Section 3
│   └── Mind Map
└── ...
```

每个小节对应一份学习导图，用于记录该部分的核心知识结构。

## 📝 学习方式

整体学习流程为：

**阅读原书 → 理解概念 → 梳理逻辑 → 绘制导图 → 回顾并修正**

导图并不是对书籍内容的替代，而是作为阅读之后的二次整理，用于帮助自己建立更加清晰、系统的理解。
