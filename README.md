# 📝 Learning Philosophy

学习不仅是记忆知识，更重要的是建立自己的理解体系。

因此这里记录的不只是：

> “这个算法是什么”

还包括：

- 它为什么出现？
- 它相比以前的方法有什么改进？
- 它的核心思想是什么？
- 它有哪些限制？
- 它未来的发展方向是什么？
